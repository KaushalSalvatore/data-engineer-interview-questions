#### Data Engineer Interview Questions

- Data Engineering is the field focused on building systems and pipelines that collect, store, process, and deliver data so that it 
can be used for analytics, reporting, and machine learning.

#### Key Concepts in Data Engineering
- ETL / ELT
- Batch vs Streaming
- Data Lakes & Data Warehouses
- Distributed systems (Spark)
- Orchestration (Airflow)
- Cloud platforms (AWS, Azure, GCP)
- Data modeling (Star schema, Snowflake schema)

#### Tools Commonly Used
- Python
- SQL
- Spark / PySpark
- Kafka
- Airflow
- Snowflake
- AWS
- dbt

#### Types of Data Engineering

- Batch Data Engineering – Processing large volumes periodically
- Streaming Data Engineering – Real-time data pipelines
- Platform Engineering – Building data infrastructure
- Analytics Engineering – Data modeling using tools like dbt
